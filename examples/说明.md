# 协议与控制面板示例

本目录存放可被后续 validator / contract test 消费的正例。**不得**写入 API key、token、私钥或可还原凭据。

## 目录

| 路径 | 覆盖 | Schema / 协议 |
|------|------|----------------|
| `affair-create.envelope.json` | 事务创建 | `envelope` + `affair` |
| `job-blocked.envelope.json` | 任务页 blocked | `envelope` + `job` |
| `job-completed.envelope.json` | worker 完成（≠ affair closed） | `envelope` + `job` |
| `control-panel/overview-snapshot.json` | 总览五卡 + 当前事务 | `control-panel-snapshot` |
| `control-panel/permission-queue.json` | 总览待确认 / 权限页队列 | `control-panel-reports` → PermissionQueue |
| `control-panel/diagnostic-report.json` | 诊断页报告 | `control-panel-reports` → DiagnosticReport |
| `control-panel/last-error-summary.json` | 最近错误摘要 | `control-panel-reports` → LastErrorSummary |
| `tasks/job-progress.envelope.json` | 任务页进度 | `job.progress` |
| `tasks/affair-waiting-acceptance.envelope.json` | 任务页待验收 | `affair.update` → `waiting_acceptance` |
| `permissions/permission-request.envelope.json` | 权限请求协议面 | `permission.request` |
| `zhang-boss/chat-message.envelope.json` | 张老板页文字输入 | `chat.message`（untrusted） |
| `zhang-boss/chat-context-attach.envelope.json` | 张老板页路径/日志附加 | `chat.context_attach`（untrusted） |

控制面板 UI 契约说明见 [控制面板数据契约.md](../docs/共同维护/技术设计/控制面板数据契约.md)。
