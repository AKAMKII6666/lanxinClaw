# 项目地图

## 仓库职责

本仓库负责 Lanxing Claw protocol、desktop companion shell 与 OpenClaw integration boundary。

本仓库不负责澜星电话 call chain、张老板人格 prompt，也不负责 OpenClaw core execution internals。

## 当前事实

- 根目录已启用 npm workspaces（`apps/*`、`packages/*`）与共享 `tsconfig.base.json`。
- `packages/protocol`：types、validators、states、examples contract tests 已落地，并接入 `npm run quality`；含张老板 companion FC catalog（`COMPANION_FC_NAMES` / `COMPANION_FC_CATALOG`）。
- `apps/mock-companion`：本地 mock 闭环（pairing / job 事件流 / 控制面板 UI 契约）已落地。
- `apps/companion`：discovery、pairing、identity、Electron 壳、bridge、总览/任务/权限/诊断/张老板页、permission gate 已按 v1.2 MVP 推进；低风险编排（`enqueueLowRiskPermission` + `runLowRiskJob`）经 gate 委派 adapter，`job.completed` 不映射为 `affair.closed`（演示：`demo:low-risk-job`）。v1.3 已补：`supervision` 监督 tick / 阻塞文案 / 验收策略、`audit` 内存审计、`chat/delivery`+`pending-context` 精确文本通道、托盘开机启动与重连策略、任务详情脉络与权限页审计区；端到端脚本 `scripts/e2e/run-v1-3-loop.ts`。**桌面 UI 可启动**：`npm run dev:companion`（Vite + Electron）或 `npm run start:companion`（先打包再开窗）；页面仍多为 demo 数据。
- `packages/openclaw-adapter`：已实现 create/read/cancel job API（`OpenClawAdapter`），对接 `OpenClawRuntimeClient`；含 mock runtime 与本机 `createLocalSafeRuntimeClient`（白名单只读：`workspace.list_root` / `git.status`，workspaceHint 不得越出授权根）。真实 Gateway / `@openclaw/sdk` 接线仍待后续。
- OpenClaw 接入路线见 [OpenClaw勘探记录.md](./OpenClaw勘探记录.md)：优先进程外 App SDK / Gateway client，默认不改 core。
- v1.3 设计已落地：[电话侧事务簿.md](../共同维护/技术设计/电话侧事务簿.md)、[张老板伴侣工具.md](../共同维护/技术设计/张老板伴侣工具.md)、[阻塞沟通策略.md](../共同维护/技术设计/阻塞沟通策略.md)、[事务验收策略.md](../共同维护/技术设计/事务验收策略.md)（本仓不实现电话主仓，只约束 store/FC 与 companion 监督边界）。
- 控制面板 UI 契约示例位于 `examples/control-panel/`；任务/权限/张老板协议示例如 `examples/说明.md`。

## 实施阶段

1. Protocol 与 security contract。
2. 本地 mock bridge 与 schema validation。
3. Companion pairing 与 permission UI。
4. OpenClaw adapter job API + local-safe 只读实跑（Gateway 端到端仍待）。
5. 澜星电话接入与张老板 affair loop。

## 验证策略

- Protocol docs：examples 必须匹配 JSON Schema。
- Protocol package：覆盖 validation 和 state transition 的 unit test。
- Companion：覆盖 pairing、permissions、reconnect、blocked jobs、low-risk job 编排的 integration / contract test（`npm run test -w @lanxin-claw/companion`）。
- OpenClaw adapter：mock runtime + local-safe contract test（`npm run test -w @lanxin-claw/openclaw-adapter`），并接入 `npm run quality`。
