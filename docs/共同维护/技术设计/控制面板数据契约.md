# 控制面板数据契约

本文定义 companion backend → 控制面板 renderer 的数据面。它不是 phone ↔ companion 的业务协议 message；phone 协议仍以 [协议/说明.md](协议/说明.md) 与 [协议/消息目录.md](协议/消息目录.md) 为准。

## 边界

| 项 | 约定 |
|----|------|
| Owner | companion backend 聚合；renderer 只读消费 |
| 方向 | companion backend → renderer（经本地 bridge） |
| 认证 | 本机进程内 bridge；不得经未配对网络暴露 |
| 禁止 | renderer 直读 API key、文件系统、命令、git、网络副作用 |
| 禁止 | 契约 payload 含 API key、token、私钥或完整 secret |
| 真源 | 本文 + `schemas/control-panel-snapshot.schema.json` + `schemas/control-panel-reports.schema.json` |
| 兼容策略 | `0.1` draft；校验层严格：未知字段（`additionalProperties: false`）与必填缺失一律整包拒绝；渲染层不得依赖未声明字段，即便未来收到多字段也不应静默当契约真源 |

总览、任务、权限、诊断、张老板页的产品字段见 [控制面板设计说明](../需求/澜星claw控制面板设计/说明.md)。本文只钉死可实现的数据形状。

## 对象总览

| 对象 | Schema | 覆盖页面 | 任务 |
|------|--------|----------|------|
| `ControlPanelSnapshot` | [control-panel-snapshot.schema.json](../../../schemas/control-panel-snapshot.schema.json) | 总览五卡 + 当前事务摘要 | V1.0-03 |
| `PermissionQueue` | [control-panel-reports.schema.json](../../../schemas/control-panel-reports.schema.json) | 总览待确认、权限页队列 | V1.0-04 |
| `DiagnosticReport` | 同上 | 诊断页 | V1.0-04 |
| `LastErrorSummary` | 同上 | 诊断「最近错误」、总览异常提示 | V1.0-04 |

## V1.0-03：状态快照 `ControlPanelSnapshot`

一屏回答：companion 是否可用、Claw core 是否运行、凭据是否就绪、电话是否已连、张老板是否在线、当前有没有要盯的事务。

### 顶层字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `schemaVersion` | `"0.1"` | 契约版本 |
| `snapshotId` | string | 本次快照 id，便于日志与 diff |
| `generatedAt` | date-time | companion backend 生成时间 |
| `companion` | object | companion 服务自身状态 |
| `clawCore` | object | OpenClaw core / worker runtime 状态 |
| `credential` | object | API key 等凭据**状态**，不含明文 |
| `device` | object | 澜星电话配对与连接摘要 |
| `zhangBoss` | object | 张老板在线与监督摘要 |
| `currentAffair` | object \| null | 当前优先展示的事务摘要；无事务时为 `null` |

### `companion`

| 字段 | 说明 |
|------|------|
| `status` | `stopped` / `starting` / `running` / `degraded` / `error` |
| `version` | companion 版本字符串，可空 |
| `uptimeMs` | 已运行毫秒；未运行可为 `null` |
| `message` | 给用户看的短说明，可空 |

### `clawCore`

| 字段 | 说明 |
|------|------|
| `status` | `not_installed` / `stopped` / `starting` / `running` / `error` |
| `version` | 检测到的 OpenClaw 版本，可空 |
| `adapterReady` | adapter 是否可接 job |
| `message` | 短说明；异常时解释用户可做什么 |

OpenClaw 只做 worker。本对象不表示张老板人格，也不表示 pairing 权威。

### `credential`

| 字段 | 说明 |
|------|------|
| `status` | `missing` / `synced` / `expired` / `needs_reauth` |
| `provider` | 凭据用途标签，如 `openclaw-api`；不是 key 本身 |
| `lastSyncedAt` | 最近同步时间，可空 |
| `expiresAt` | 过期时间，可空 |
| `message` | 短说明 |

**硬约束：** 不得出现 key 原文、token、私钥或可还原密文。

### `device`

| 字段 | 说明 |
|------|------|
| `status` | `undiscovered` / `discovered` / `pairing` / `connected` / `disconnected` |
| `phoneDeviceId` | 已配对或发现中的电话设备 id，可空 |
| `phoneDisplayName` | 展示名，可空 |
| `pairingId` | 进行中或最近配对 id，可空 |
| `sessionId` | 当前 session id，可空 |
| `fingerprintHint` | 截断指纹提示（如 `8F:2A:…`），不得是完整私钥 |
| `lastSeenAt` | 最近可见时间，可空 |
| `message` | 短说明 |

Discovery ≠ trust。`discovered` 不得被 UI 渲染成“已授权执行”。

### `zhangBoss`

| 字段 | 说明 |
|------|------|
| `status` | `offline` / `online` / `in_call` / `supervising` / `waiting_user` |
| `activeAffairId` | 正在盯的事务 id，可空 |
| `activeCallId` | 当前通话 id，可空 |
| `summary` | 一句话责任人摘要，可空 |

### `currentAffair`（可空）

| 字段 | 说明 |
|------|------|
| `affairId` | 事务 id |
| `title` | 标题 |
| `status` | 与 affair schema 对齐：`clarifying` / `ready` / `delegated` / `running` / `blocked` / `paused` / `waiting_acceptance` / `closed` / `canceled` |
| `currentJobId` | 当前 job id，可空 |
| `executor` | 当前执行者标签，如 `openclaw`；无 job 可空 |
| `progressSummary` | 给用户看的最近进展 |
| `blockedReason` | blocked 时原因，否则 `null` |
| `resumeCondition` | 恢复条件，可空 |
| `updatedAt` | 最近状态变化时间 |

**硬约束：** job / worker `completed` 不得把本摘要自动写成 affair `closed`。完成后应进入 `waiting_acceptance`，直到用户接受或明确取消。

## V1.0-04：队列与报告

### `PermissionQueue`

待确认队列供总览「待确认」与权限页消费。条目由 companion permission gate 产生；renderer 只提交用户选择，最终授权仍在 companion backend。

#### 顶层

| 字段 | 说明 |
|------|------|
| `schemaVersion` | `"0.1"` |
| `queueId` | 队列快照 id |
| `generatedAt` | 生成时间 |
| `pendingCount` | 待处理条数，须等于 `items` 中 `pending` 数量 |
| `items` | 队列项数组，按 `requestedAt` 升序 |

#### `items[]`

| 字段 | 说明 |
|------|------|
| `permissionRequestId` | 与 `permission.request` 对齐 |
| `queueStatus` | `pending` / `decided` / `expired` |
| `requester` | `zhang-boss` / `companion` / `openclaw-adapter` |
| `affairId` | 可空 |
| `jobId` | 关联 job |
| `requestedPermissions` | permission id 列表 |
| `reason` | 为什么需要 |
| `risk` | `low` / `medium` / `high` |
| `proposedScope` | workspace / commands / networkHosts；不得含 secret |
| `availableDecisions` | UI 可点选项：`allow_once` / `allow_for_job` / `deny` / `require_more_context` |
| `denyConsequence` | 拒绝后会发生什么（用户可见文案） |
| `requestedAt` | 入队时间 |
| `expiresAt` | 过期时间，可空 |

已决策项可短暂保留供 UI 消融动画，但 `pendingCount` 只统计 `pending`。

### `DiagnosticReport`

诊断页的结构化报告，禁止靠临时拼接日志冒充契约。

#### 顶层

| 字段 | 说明 |
|------|------|
| `schemaVersion` | `"0.1"` |
| `reportId` | 报告 id |
| `generatedAt` | 生成时间 |
| `overallStatus` | `ok` / `warn` / `error` |
| `services` | 服务探针列表 |
| `environment` | 环境探针列表 |
| `lastError` | `LastErrorSummary` 或 `null` |
| `copyText` | 可供「复制诊断报告」的纯文本摘要；仍不得含凭据明文 |

#### 探针项（`services[]` / `environment[]`）

| 字段 | 说明 |
|------|------|
| `probeId` | 稳定 id，如 `companion.service`、`env.node` |
| `label` | 中文展示名 |
| `category` | `service` 或 `environment` |
| `status` | `ok` / `warn` / `error` / `unknown` |
| `detail` | 检测细节（版本号、路径存在与否等），不得含 secret |
| `hint` | 用户可采取的下一步，可空 |

建议 `probeId`（v1.0 最小集）：

| probeId | category | 对应设计稿项 |
|---------|----------|--------------|
| `companion.service` | service | Companion service |
| `openclaw.core` | service | OpenClaw core |
| `credential.api` | service | API key 配置态（无明文） |
| `secure.storage` | service | Secure storage |
| `env.node` | environment | Node |
| `env.package_manager` | environment | pnpm/npm |
| `env.git` | environment | Git |
| `net.lan_discovery` | environment | LAN discovery |
| `net.firewall` | environment | Firewall |

### `LastErrorSummary`

| 字段 | 说明 |
|------|------|
| `occurredAt` | 发生时间 |
| `code` | 稳定错误码，如 `job.blocked`、`pairing.timeout` |
| `severity` | `info` / `warn` / `error` |
| `message` | 用户可读摘要 |
| `affairId` | 关联事务，可空 |
| `jobId` | 关联 job，可空 |
| `retryable` | 是否可重试或 resume |

## 与 phone 协议的关系

| UI 契约 | phone 协议来源 | 注意 |
|---------|----------------|------|
| `currentAffair` | `affair.*` / `job.*` 状态投影 | UI 摘要 ≠ 完整 affair 对象 |
| `device` | `pairing.*` / `session.*` | 不得用发现到端口代替已认证 |
| `PermissionQueue.items` | `permission.request` + 本地未决决策 | 用户决策经 backend 后再发 `permission.decision` |
| `clawCore` / `credential` / probes | companion 本地状态 | 不进入 phone envelope |

控制面板不得把本契约当成可向电话端任意转发的 system instructions。`chat.message` / `chat.context_attach` 仍是 untrusted input。

## 验收（本契约层）

- schema 可校验正例；缺必填或含额外未知字段（各对象 `additionalProperties: false`）应失败；不得把“渲染可忽略未知”写成校验可放行。
- `PermissionQueue.pendingCount` 必须等于 `items` 中 `queueStatus=pending` 的条数；JSON Schema 当前不表达该不变量，由实现与测试强制（正例：`pendingCount=1` 且仅一条 pending；反例：计数与 pending 条数不一致须拒绝）。
- snapshot / queue / report 示例均无凭据明文。
- `currentAffair.status` 允许 `waiting_acceptance`；文档与注释明确 worker completed ≠ affair closed。
- 后续 mock companion（V1.0-09）与 UI（v1.2）必须消费本契约，不得另起一套字段名。
