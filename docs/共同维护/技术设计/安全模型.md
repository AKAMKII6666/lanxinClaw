# 安全模型

## 安全原则

Discovery 不是 trust。Pairing 不是无限控制权。Connection 不是执行权限。

## Trust Boundaries

```text
Phone / Zhang Boss
  可信范围：conversation 与 affair intent

Companion
  可信范围：desktop-side security gate

OpenClaw Adapter
  可信范围：在 granted permissions 内 delegated execution

OpenClaw Runtime
  视为强能力 local worker，不是 pairing authority
```

## Pairing 要求

- 首次 pairing 必须要求电话侧用户明确确认。
- 首次 pairing 也应要求 desktop confirmation。
- Pairing 交换稳定 device identity。
- 后续 session 使用已保存 identity 认证，不使用 port presence。
- Paired device 必须可以 revoke。

## Credential 处理

- API key 不得进入日志。
- API key 不得明文存入 repo 文件。
- Companion 应尽量使用 OS secure storage。
- 从电话端导入的 credential 必须按 desktop companion 的需要进行 scope 限制。

## Permission Levels

Permission 由 companion 授予，不由电话端授予。

### 消费安装档（产品默认）

澜星 Claw 作为面向普通用户的安装产品时，采用分层边界（见 [0002-安装默认授权档](../决议/0002-安装默认授权档.md)）：OpenClaw 侧 browser 等工具默认开启（有头可见）；Companion 下列执行权限为 `needs_confirm`，`job.create` 后须用户确认再委派（**不做**静默 `allow_for_job`）：

| Permission | 含义 |
|------------|---------|
| `workspace.read` / `workspace.write` | 选定工作区内读/写文件 |
| `command.run` | 运行本地命令 |
| `network.access` | 联网工具与依赖网络的命令 |
| `git.read` / `git.write` | 查看 git；stage / commit / branch / push |
| `desktop.control` | 截图与 GUI/浏览器控制面 |

仍保留：

- 首次配对确认（信任设备 ≠ 上述执行权限）
- `secrets.read`：**默认拒绝**，不得静默放行
- 工作区越界检查（`authorizedDesktopRoot` / proposedScope）

产品不提供 OpenClaw `web_search` 主路径；浏览器能力由自托管配置默认开启（有头窗口）。查资料类任务首选托管浏览器，`web_fetch` 仅备用。托管浏览器本地代理默认开启（`shell-settings.json` 的 `browserProxyEnabled`，默认 URL `http://127.0.0.1:7890`）；用户可在诊断页改开关/地址并「应用并重启」。应用后 companion 会配套写入 `browser.ssrfPolicy.dangerouslyAllowPrivateNetwork=true`、`tools.web.fetch` 的 fake-IP 合法字段与 `useTrustedEnvProxy`，并向 Gateway 子进程注入同源 `HTTP_PROXY`/`HTTPS_PROXY`（关闭即清除）。查资料意图弹权时 companion 可补全 `desktop.control` + `network.access`（用户确认，非静默授权）。

### 权限表

| Permission | 含义 |
|------------|---------|
| `workspace.read` | 读取选定 project files 与 metadata |
| `workspace.write` | 修改选定 project files |
| `command.run` | 运行 allowlisted local commands |
| `network.access` | 使用依赖 network 的 commands 或 tools |
| `git.read` | 查看 git state 与 history |
| `git.write` | stage、commit、branch 或 push |
| `secrets.read` | 读取 configured secrets；默认拒绝 |
| `desktop.control` | 控制 GUI apps；任务发放仍须用户确认 |

消费安装档下，OpenClaw 工具默认开，但 companion 任务授权 UX 仍要求确认。`secrets.read` 与越界写仍拒绝。

## Audit

Companion 应保留 local audit trail：

- Pairing 与 revocation。
- Permission grant 与 denial。
- Job creation 与 actor。
- High-risk command request 与 approval。
- Blocked 与 completed job report。
