# Discovery Protocol

## 目标

允许电话端在 local network 中发现 Lanxing Claw Companion instance，但 discovery 阶段不建立 trust。

## 推荐 Transport

优先使用 mDNS / DNS-SD，而不是 port scanning。

Service name：

```text
_lanxing-claw._tcp.local
```

## Advertisement Fields

逻辑字段（协议层 / `packages/protocol` 的 `DiscoveryAdvertisement`）：

```json
{
  "deviceName": "LIAO-PC",
  "deviceIdHint": "desktop_fingerprint_hint",
  "serviceVersion": "0.1.0",
  "protocolVersion": "0.2",
  "pairingAvailable": true,
  "pairedPhoneIds": [],
  "capabilities": ["pairing.v1", "session.v1", "affairs.v1", "jobs.v1", "chat.v1"]
}
```

DNS-SD TXT 编码：上述键均为字符串值；`pairingAvailable` 为 `"true"` / `"false"`；`pairedPhoneIds` 与 `capabilities` 用逗号拼接（空列表编码为空串）。实现见 `encodeDiscoveryTxt` / `decodeDiscoveryTxt`。

Discovery data 不得包含 credentials、本地用户名、文件路径、API key 或详细项目列表。发现成功不等于已认证；不得因发现到端口授予 session。

## 电话端行为

- 低频 discovery。
- 不因每次 discovery event 都打扰用户。
- 仅在首次 pairing、blocked affair 重新连接、用户主动连接时优先提示。
