# Job Protocol

## 含义

Job 是被委派的执行工作，通常由 OpenClaw 承担。

一个 affair 可以在生命周期内创建多个 job。Job completed 不会自动关闭 affair。

`purpose` 用于区分 job 的事务语义：

| Purpose | 含义 | completed 后 affair 投影 |
|---------|------|--------------------------|
| `execution`（默认） | 用户目标与验收标准明确后的正式委派 | 只可进入 `waiting_acceptance`，仍需用户验收 |
| `exploration` | 正式事务前的只读澄清/探查 | 保持原 affair 状态，不进入验收 |

## Job Object

```json
{
  "jobId": "job_01H...",
  "affairId": "affair_01H...",
  "executor": "openclaw",
  "status": "queued",
  "purpose": "execution",
  "goal": "Inspect and fix the selected project until tests pass.",
  "workspaceHint": "F:/xxx",
  "allowedPermissions": ["workspace.read"],
  "taskIntentId": "task_intent_01H...",
  "progressSummary": "",
  "blockedReason": null,
  "resumeCondition": null,
  "permissionRequestId": null,
  "statusReasonCode": null,
  "statusObservedAt": null
}
```

## Statuses

| Status | 含义 |
|--------|---------|
| `queued` | 已 accepted，但尚未 started |
| `running` | Worker 正在 executing |
| `needs_permission` | Companion 需要 user permission |
| `blocked` | Worker 没有 external help 无法继续 |
| `completed` | Worker 认为 job goal 已完成 |
| `failed` | Worker 以 unrecoverable error 结束 |
| `canceled` | user 或 system 已取消 |

## Events

| Type | Direction | 作用 |
|------|-----------|---------|
| `job.create` | phone -> companion | 委派 execution 或 exploration；`purpose` 默认为 `execution` |
| `job.accepted` | companion -> phone | Companion 已接受 job |
| `job.progress` | companion -> phone | 进度摘要 |
| `job.needs_permission` | companion -> phone | 请求 desktop permission |
| `job.blocked` | companion -> phone | 说明 blocker 与 resume condition |
| `job.completed` | companion -> phone | Worker 完成 delegated work |
| `job.failed` | companion -> phone | Worker 执行失败 |
| `job.cancel` | phone -> companion | 取消 delegated work |
| `job.canceled` | companion -> phone | Companion 确认 delegated work 已取消 |

`purpose=exploration` 的 `job.completed` 只表示探索资料已返回，不能驱动 affair 到 `waiting_acceptance`；正式工作必须另建 `purpose=execution` job。

## 证据字段

| 字段 | Owner | Direction | 认证 | 兼容 |
|------|-------|-----------|------|------|
| `statusReasonCode` | companion | companion -> phone 的 job 事件 | session | 可空；未知 code 仅作展示/日志，不得驱动高风险动作 |
| `statusObservedAt` | companion | companion -> phone 的 job 事件 | session | 可空；ISO-8601；用于判断状态新鲜度 |
| `taskIntentId` | phone | phone -> companion 的 `job.create`，后续 job 事件应尽量携带或由接收端保留 | session | 可空；旧端没有时仍按 `messageId/jobId` 幂等 |

`job.canceled` 是取消事实，不是取消请求。phone 发出的 `job.cancel` 只表示用户意图；companion 必须经 adapter/OpenClaw 取消确认，或确认 run 尚未启动，才广播 `job.canceled`。
