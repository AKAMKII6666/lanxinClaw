# Job Protocol

## 含义

Job 是被委派的执行工作，通常由 OpenClaw 承担。

一个 affair 可以在生命周期内创建多个 job。Job completed 不会自动关闭 affair。

## Job Object

```json
{
  "jobId": "job_01H...",
  "affairId": "affair_01H...",
  "executor": "openclaw",
  "status": "queued",
  "goal": "Inspect and fix the selected project until tests pass.",
  "workspaceHint": "F:/xxx",
  "allowedPermissions": ["workspace.read"],
  "progressSummary": "",
  "blockedReason": null,
  "resumeCondition": null,
  "permissionRequestId": null
}
```

## Statuses

| Status | 含义 |
|--------|---------|
| `queued` | 已 accepted，但尚未 started |
| `running` | Worker 正在 executing |
| `needs_permission` | Companion 需要 user permission |
| `blocked` | Worker 没有 external help 无法继续 |
| `completed` | Worker 认为 job goal 已完成 |
| `failed` | Worker 以 unrecoverable error 结束 |
| `canceled` | user 或 system 已取消 |

## Events

| Type | Direction | 作用 |
|------|-----------|---------|
| `job.create` | phone -> companion | 委派 execution |
| `job.accepted` | companion -> phone | Companion 已接受 job |
| `job.progress` | companion -> phone | 进度摘要 |
| `job.needs_permission` | companion -> phone | 请求 desktop permission |
| `job.blocked` | companion -> phone | 说明 blocker 与 resume condition |
| `job.completed` | companion -> phone | Worker 完成 delegated work |
| `job.failed` | companion -> phone | Worker 执行失败 |
| `job.cancel` | phone -> companion | 取消 delegated work |
