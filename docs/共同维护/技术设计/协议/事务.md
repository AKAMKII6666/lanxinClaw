# Affair Protocol

## 含义

Affair 是张老板管理的日常事务承诺，不是 database transaction。

电话侧持久化与挂机恢复见 [电话侧事务簿.md](../电话侧事务簿.md)。张老板通过 companion FC 委派/暂停/恢复时，仍须遵守本节状态机；`job.completed` 不得直接变为 `closed`。

## Affair Object

```json
{
  "affairId": "affair_01H...",
  "title": "Fix the xxx project code issue",
  "ownerAgent": "zhang-boss",
  "status": "clarifying",
  "context": [
    "The project is on drive F.",
    "The user says the code seems broken."
  ],
  "acceptanceCriteria": [
    "Tests pass.",
    "The user accepts the result."
  ],
  "blockedReason": null,
  "resumeCondition": null,
  "currentJobId": null
}
```

## Statuses

| Status | 含义 |
|--------|---------|
| `clarifying` | 张老板正在追问缺失 context |
| `ready` | context 与 acceptance criteria 已足够开始 |
| `delegated` | 已创建 worker job |
| `running` | 工作正在推进 |
| `blocked` | 需要 user、desktop 或 external action 才能继续 |
| `paused` | user 或 system 暂停 affair |
| `waiting_acceptance` | worker 认为 done，但 user 尚未验收 |
| `closed` | user 已验收或明确关闭 |
| `canceled` | user 已取消 |

## Events

| Type | Direction | 作用 |
|------|-----------|---------|
| `affair.create` | phone -> companion | 创建或 mirror 一个 affair |
| `affair.update` | either | 更新 context、status、blocker 或 criteria |
| `affair.resume` | phone -> companion | 从已知 resume condition 继续 |
| `affair.close` | phone -> companion | 用户验收或明确取消后关闭；payload `status` 为 `closed` 或 `canceled`（详见[消息目录.md](消息目录.md) `affair.close`） |
