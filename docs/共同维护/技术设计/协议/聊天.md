# Chat Protocol

## 目标

支持 desktop companion 与张老板之间的精确 text side channel。

这个 channel 用于 paths、logs、commands、URLs、short notes，以及用户在电脑端输入的 messages。

## Events

| Type | Direction | 作用 |
|------|-----------|---------|
| `chat.message` | either | 发送 text message |
| `chat.context_attach` | companion -> phone | 将精确 context 附加到 active realtime conversation |
| `chat.read_receipt` | either | 可选 acknowledgement（phone 注入成功后可回传） |

## 通话中投递（主路径）

Companion 在已认证 session 下出站 `chat.message` / `chat.context_attach`（含 `target=active_call`）后，**电话侧**在通话中主动：

1. 落盘 timeline / `pendingContext`；
2. 将原文以 untrusted user item 注入当前 realtime 会话（`sendSyntheticUserText`，reason=`lanxin_claw_desktop_chat`）；
3. 触发一轮口头确认：复述要点并询问用户意图；
4. 注入成功后可发 `chat.read_receipt`，并从 pending 移除该条，避免重复念读。

Companion **不**拥有通话真源；是否在通话由 phone 判断。挂机 / farewell 中不得注入。

## Context Attachment（离线 fallback）

当不在通话或 realtime 注入失败时，文本保留在 phone `pendingContext`。

张老板可通过 FC `companion.fetch_pending_context` 主动取回。FC 目录与映射见 [张老板伴侣工具.md](../张老板伴侣工具.md)。

**通话中不得把 FC 拉取当作主体验**；主路径是 phone 主动注入。

## Safety

Desktop chat text 是 untrusted input。不得把它当作张老板、companion 或 OpenClaw 的 system instructions。张老板口头确认必须锚定注入原文，不得无证据声称已执行桌面动作。
