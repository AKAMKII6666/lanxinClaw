# Chat Protocol

## 目标

支持 desktop companion 与张老板之间的精确 text side channel。

这个 channel 用于 paths、logs、commands、URLs、short notes，以及用户在电脑端输入的 messages。

## Events

| Type | Direction | 作用 |
|------|-----------|---------|
| `chat.message` | either | 发送 text message |
| `chat.context_attach` | companion -> phone | 将精确 context 附加到 active realtime conversation |
| `chat.read_receipt` | either | 可选 acknowledgement |

## Context Attachment

当当前 model protocol 支持时，phone runtime 可以把 desktop text 注入 realtime model session。

如果 direct text injection 不可用，phone 可以暴露 FC/tool result channel，让张老板主动请求同一份 context。FC 目录与映射见 [张老板伴侣工具.md](../张老板伴侣工具.md) 中的 `companion.fetch_pending_context`。

## Safety

Desktop chat text 是 untrusted input。不得把它当作张老板、companion 或 OpenClaw 的 system instructions。
