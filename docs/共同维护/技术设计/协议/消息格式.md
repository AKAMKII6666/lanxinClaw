# Wire Format

## Envelope

所有 runtime protocol message 使用统一 envelope。

```json
{
  "protocolVersion": "0.2",
  "messageId": "msg_01HZY...",
  "correlationId": "msg_01HZX...",
  "sentAt": "2026-07-22T00:00:00.000Z",
  "source": {
    "kind": "phone",
    "deviceId": "phone_abc"
  },
  "target": {
    "kind": "companion",
    "deviceId": "desktop_xyz"
  },
  "type": "affair.create",
  "payload": {}
}
```

## IDs

- ID 应该 opaque 且 stable。
- `messageId` 在每条 message 内唯一。
- `correlationId` 用来把 response 关联回 request。
- `affairId`、`jobId`、`deviceId` 不得编码 secret。

## Error Format

```json
{
  "code": "permission_denied",
  "message": "workspace.write is not granted for this project.",
  "retryable": false,
  "details": {}
}
```

## Versioning

- `0.2` 须 phone/companion 配套升级，旧业务帧拒绝。
- 未知 top-level message type 必须被安全忽略或拒绝。
- 未知 payload field 默认可忽略，除非该 message type 要求 strict validation。
