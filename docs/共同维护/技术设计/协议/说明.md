# 协议总览

Lanxing Claw protocol 连接澜星电话与 desktop companion。

## 协议分区

| 分区 | 文件 | 作用 |
|------|------|---------|
| Wire format | [消息格式.md](消息格式.md) | 通用 message envelope、ids、errors、versioning |
| Message catalog | [消息目录.md](消息目录.md) | 全部 runtime message type：方向、认证、payload、错误与兼容 |
| Discovery | [发现.md](发现.md) | LAN service discovery 与 capability advertisement |
| Pairing | [配对.md](配对.md) | 首次 trust establishment 与 revocation |
| Session | [会话.md](会话.md) | 已认证 runtime connection 与 heartbeat |
| Affairs | [事务.md](事务.md) | 张老板负责的 responsibility objects |
| Jobs | [作业.md](作业.md) | 委派给 OpenClaw 的 work 与 status reports |
| Chat | [聊天.md](聊天.md) | 张老板与 desktop 之间的 text side channel |
| Permissions | [权限.md](权限.md) | Desktop-side permission requests 与 grants |

电话侧事务簿与张老板 companion FC（非 envelope type，映射到上表消息）见 [电话侧事务簿.md](../电话侧事务簿.md)、[张老板伴侣工具.md](../张老板伴侣工具.md)。

控制面板 UI 数据面（snapshot / permission queue / diagnostic report）不是本协议分区的 phone↔companion message，见 [控制面板数据契约.md](../控制面板数据契约.md)。

## 方向命名

- `phone -> companion`：电话端或张老板向 desktop companion 发送 request。
- `companion -> phone`：desktop companion 向电话端发送 status、chat 或 request。
- `companion -> adapter`：desktop companion 委派给 OpenClaw。
- `adapter -> companion`：adapter 回报 execution status。

## 兼容性

每条 message 都携带 `protocolVersion`。`0.2` 是本次两端配套升级的协议版本；旧业务帧必须拒绝。

## 与 `packages/protocol` 对齐

共享实现位于 `packages/protocol`：types、validators、message helpers、errors、ids，以及 message type → 顶层 `schemas/*.schema.json` 的登记表（`schemas/registry.ts`）。

| 真源 | 包内对应 |
|------|----------|
| `schemas/envelope.schema.json` | `validateEnvelope` / `ProtocolEnvelope` |
| `schemas/affair.schema.json` 等 payload schema | `validatePayloadForType` / `validateMessage` |
| `schemas/control-panel-*.schema.json` | `validateControlPanelSnapshot` 等 UI validators |
| `examples/**/*.json` | `packages/protocol/tests` 消费正例 |

变更协议字段时必须同步：专题文档、顶层 schema、本包 types/validators，以及可被测试消费的 examples。

当前产品收尾变更见 [协议 0.2 收尾合同](v0.2收尾合同.md)，包括配套升级、关联回执和共同关闭协调器。
