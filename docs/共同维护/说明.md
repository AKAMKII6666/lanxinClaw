# Shared 文档

Shared 文档是人类与 Agent 共同接受的协作真源。

## 分册

| 目录 | 作用 |
|-----------|---------|
| `requirements/` | 产品行为、用户体验、验收标准 |
| `technical-design/` | 工程设计、协议、拓扑、安全、代码落点 |
| `plans/` | roadmap、执行索引、阶段任务 |
| `decisions/` | 带日期的已拍板决议 |

## 冲突规则

实现事实以当前代码和测试为准。产品方向变化必须先更新 requirements 或 decisions，不能让代码悄悄漂移。
