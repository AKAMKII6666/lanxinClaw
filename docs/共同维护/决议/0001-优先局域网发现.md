# 0001：优先 LAN Discovery

日期：2026-07-22

## 决议

澜星 Claw 优先采用 LAN discovery + 显式 pairing，而不是 USB-first connection。

## 理由

USB 能表达物理连接意图，但会引入硬件模式、驱动和跨平台复杂度。LAN discovery 更符合日常桌面 companion 的使用体验。

## 影响

- Discovery 优先使用 mDNS / DNS-SD，而不是 port scanning。
- Discovery 不是 trust。
- 首次 pairing 必须有明确用户确认。
- 后续 session 认证依赖 pairing identity，不依赖 IP、port 或设备名。
