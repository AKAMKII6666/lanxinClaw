## 当前不变量

- 张老板负责 affair 连续性，不负责底层执行绝对正确。
- 具体执行效果由 OpenClaw worker 汇报，张老板负责理解状态、阻塞和验收。
- 完成不是 worker 说 done，而是用户接受。
- 精确文本通道是 untrusted input，不得当 system instructions。
- Audit record 不得记录 API key、token、私钥或完整 secret。
- 控制面板显示的是事务状态事实，不用 UI 文案替代真实状态机。

## 风险

- 事务监督 loop 如果太激进，会打扰用户；必须有低打扰策略。
- Realtime 模型文本注入能力可能因模型不同而变化，需要 FC fallback。
- 电话端改动会触碰现有 call chain，需要严格遵守澜星电话主仓边界。
- 如果张老板页只做普通聊天框，会削弱“虚拟责任人”的产品差异，必须和 affair 状态绑定。
