# 路线图

## 版本总览

| 版本 | 主题 | 覆盖阶段 | 结束标志 |
|------|------|----------|----------|
| v1.0 | 协议与 mock companion 闭环 | P0、P1、P2 | 不接 OpenClaw，也能验证 affair/job/message/status 闭环 |
| v1.2 | 真实 companion、pairing 与 OpenClaw adapter 闭环 | P3、P4、P5、P6 | 电脑端可发现、可配对、可授权，并能把低风险 job 交给 OpenClaw adapter |
| v1.3 | 张老板事务体验与产品化闭环 | P7、P8、P9、P10 | 张老板能后台盯事务、处理 blocked/resume、完成后等待用户验收 |

## v1.0：协议与 mock companion 闭环

### P0：协议收敛

- 仓库导航与规则。
- 协议文档。
- 核心对象的 JSON Schema。
- 示例 message。

### P1：Mock Companion

- 本地 WebSocket server。
- 内存版 pairing mock。
- Affair/job message validation。
- Mock OpenClaw adapter 返回 progress、blocked、completed 状态。

### P2：Protocol SDK

- `packages/protocol`。
- 提供 types、validators 与 message helpers。
- examples 与 schema validator 对齐。
- protocol tests 接入 `npm run quality`。

## v1.2：真实 companion、pairing 与 OpenClaw adapter 闭环

### P3：Pairing MVP

- LAN discovery。
- mDNS advertisement。
- 配对请求、桌面确认、设备身份保存。
- revoke 与 reconnect。

### P4：Companion 壳 MVP

- Desktop UI shell。
- 带 desktop confirmation 的首次 pairing flow。
- 设备状态、任务状态、权限请求。
- 本地 permission UI。
- 安全 credential storage。

### P5：OpenClaw Adapter 探勘

- 源码勘探报告。
- 启动入口、job/run/channel/config/扩展点。
- 明确 adapter、plugin、gateway client 或少量 patch 路线。

### P6：OpenClaw Job 闭环

- 启动或 attach 到 OpenClaw runtime。
- 根据 Lanxing job 创建 OpenClaw run。
- 将 progress stream 回 companion。
- 将 OpenClaw error 映射为 Lanxing job state。

## v1.3：张老板事务体验与产品化闭环

### P7：张老板事务接入

- 澜星电话发现 companion。
- 张老板创建 affair。
- Affair store、FC、后台监督、阻塞/完成回报。
- 挂电话后事务仍在，阻塞可恢复，完成进入等待验收。

### P8：精确文本通道

- Chat context 可以把精确路径或日志补进 active conversation。
- 电脑端 UI 输入路径、日志、URL。
- Realtime text injection 可用则直注入，不可用则走 FC fallback。

### P9：权限与审计

- 权限分级。
- 一次性授权和 job scope 授权。
- 高风险动作确认。
- Audit log。

### P10：产品化迭代

- 安装、托盘、开机启动。
- 自动重连。
- Blocked/completed affair 触发 call-back 或提醒。
- 日常可用，不需要开发者手动开服务。
