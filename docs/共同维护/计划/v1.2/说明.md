# v1.2 计划说明

## 版本目标

v1.2 的目标是跑通“真实电脑 companion 到 OpenClaw adapter”的本机闭环。

v1.0 证明协议能跑，v1.2 要证明电脑端真的能被发现、配对、授权，并把 job 委派到 OpenClaw 执行层。

本版本也是 Windows 控制面板 MVP 的落地版本。控制面板不再是静态设计稿，而要连接 companion backend，展示真实服务状态、连接状态、任务状态、权限请求和诊断结果。

## 对应阶段

| 阶段 | 目标 | 产出 | 完成标准 |
|------|------|------|----------|
| P3 Pairing MVP | 做局域网发现和配对最小闭环 | mDNS discovery、配对请求、桌面确认、设备身份保存 | 模拟电话能发现电脑并完成首次 pairing |
| P4 Companion 壳 MVP | 做电脑端最小 UI | Electron shell、总览、任务、权限、诊断、首次 pairing 弹窗、张老板基础入口 | 用户能在电脑上看到连接、任务、授权请求和诊断结果 |
| P5 OpenClaw Adapter 探勘 | 研究 OpenClaw 可接入点 | 源码勘探报告：启动入口、job/run/channel/config/扩展点 | 明确 adapter、plugin、gateway client 或少量 patch 路线 |
| P6 OpenClaw Job 闭环 | 真正把任务派给 OpenClaw | `packages/openclaw-adapter`，能创建任务、读状态、取消 | 张老板创建事务后，OpenClaw 能执行一个安全任务 |

## 范围

- 实现 LAN discovery。
- 实现首次 pairing 的双确认流程。
- 实现 device identity 存储与 revoke。
- 实现 companion 最小 UI。
- 按控制面板设计稿实现总览、任务、权限、诊断和首次 Pairing 弹窗。
- 实现张老板页的基础入口，支持展示状态和提交文字上下文，但不要求完整监督体验。
- 实现 renderer 与 companion backend 的安全 bridge。
- 实现本地 permission UI。
- 完成 OpenClaw 源码勘探报告。
- 实现 OpenClaw adapter 最小 job API。
- 跑通一个安全任务，例如读取项目目录、查看 git status 或运行只读检查。

## 非目标

- 不要求完整产品级安装器。
- 不做长期后台回电策略。
- 不在 v1.2 深化张老板责任人话术和后台监督策略。
- 不把张老板人格逻辑写进 OpenClaw core。
- 不支持高风险 desktop control。
- 不实现跨公网 relay。

## 控制面板 MVP 范围

| 页面 | v1.2 要实现 | 暂不实现 |
|------|-------------|----------|
| 总览 | 五个状态卡、当前任务、待确认入口 | 复杂图表和历史趋势 |
| 任务 | 事务列表、任务详情、状态变化、基础操作 | 多人协作和复杂筛选 |
| 张老板 | 在线状态、当前事务、文字上下文提交 | 完整聊天历史治理和回电策略 |
| 权限 | 已配对设备、当前 job 权限、待确认卡片 | 永久规则编辑器的复杂策略 |
| 诊断 | 服务检查、环境检查、最近错误、复制报告 | 自动修复所有系统问题 |
| 首次 Pairing | 设备指纹、双确认提示、允许或拒绝 | 跨公网 relay 和云端账号绑定 |

Renderer 只负责展示和提交用户选择。API key、命令执行、文件访问、git 操作、网络访问和 permission decision 的最终落点都必须在 companion backend。

## v1.2 闭环

```text
模拟电话/张老板
  -> LAN discovery
  -> pairing.request
  -> desktop confirmation
  -> companion UI state update
  -> session.open
  -> job.create
  -> companion permission gate
  -> permission confirmation UI
  -> OpenClaw adapter
  -> job.progress / job.completed
```

## 验收标准

- `npm run quality` 通过。
- Companion 可以被 LAN discovery 发现。
- 首次 pairing 必须经过电话侧与电脑侧确认。
- 已配对 device 可以重连，也可以 revoke。
- Companion UI 能展示连接状态、任务状态、权限请求。
- 总览、任务、权限、诊断和首次 Pairing 弹窗与设计稿的信息架构一致。
- Renderer 无法绕过 companion backend 直接执行文件、命令、git、网络或 credential 副作用。
- OpenClaw adapter 能执行一个低风险任务并回传状态。
