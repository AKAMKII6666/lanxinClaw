## 当前不变量

- Discovery 不等于 trust。
- Pairing 不等于执行权限。
- Permission 由 companion 决定，不由电话端决定。
- Renderer 只是展示层和用户输入层，不能直接访问 API key、文件系统、命令执行、git 或网络副作用。
- OpenClaw 是 worker，不是张老板人格或 pairing authority。
- 任何文件、命令、网络、git 副作用都必须经过 companion permission gate。

## 风险

- OpenClaw 可接入点可能不稳定，需要 adapter 与少量 patch 两手准备。
- mDNS 在不同网络环境下可能不稳定，需要保留手动输入地址作为 debug 路径。
- Companion UI 若过早做复杂，会拖慢协议与执行闭环；v1.2 只做设计稿覆盖的 MVP 页面。
- 如果 renderer/backend bridge 边界不硬，会让权限模型被前端实现绕开。
