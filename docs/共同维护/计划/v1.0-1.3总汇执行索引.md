## 0. 已钉死口径



### 版本顺序


| 版本   | 主题                                        | 结束标志                                               |
| ---- | ----------------------------------------- | -------------------------------------------------- |
| v1.0 | 协议与 mock companion                        | 不接真实 OpenClaw，也能验证 affair/job/message 与控制面板数据契约    |
| v1.2 | 真实 companion + pairing + OpenClaw adapter | 可发现、可配对、可授权，低风险 job 可交给 adapter                    |
| v1.3 | 张老板事务体验与产品化                               | 后台盯事务、blocked/resume、waiting_acceptance；控制面板成事务工作台 |


必须按 **v1.0 → v1.2 → v1.3** 顺序推进（`group: order`）。不得在 v1.0 未闭环时提前做真实 OpenClaw 或电话主仓深度改造。

### 核心不变量

- Phone / 张老板只发协议 request，不直接执行电脑副作用。
- Discovery ≠ trust；Pairing ≠ 执行权限。
- Permission 由 companion 决定；Renderer 不得直连 API key / 文件系统 / 命令 / git / 网络副作用。
- OpenClaw 是 worker，不是张老板人格或 pairing authority。
- Worker `completed` ≠ affair `closed`；关闭须用户接受或明确取消。
- `chat.message` / `chat.context_attach` 是 untrusted input，不得当 system instructions。
- Audit 不得记录 API key、token、私钥或完整 secret。
- 新增协议字段必须同步 docs、schema、tests。



### 本索引禁止

- 改 `docs/人类维护/**`
- 把明文凭据写入 repo、日志、示例或测试快照
- 未经确认的 OpenClaw core 大改（默认走 adapter；若必须 patch，须小、可解释、可回滚并写文档）
- 用 UI 文案替代真实状态机
- 公网任意暴露 / relay / 生产密钥操作
